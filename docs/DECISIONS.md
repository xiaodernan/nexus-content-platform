# Decisions

The canonical decision log is the ADR set in [`./decisions/`](decisions/). See
[decisions/README.md](decisions/README.md) for the index (ADR 0001–0017). Every major
architectural choice is captured there in Decision/Context/Options/Choice/Reason/Tradeoffs/Date
form (§78). New decisions: copy [decisions/template.md](decisions/template.md).
