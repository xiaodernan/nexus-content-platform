## 与主线的关系

- **同一原始约束**：不续写第三章之后的正典；所有提问的人都在找「收件人」；
  所有回响都发生在潮候院建院之后的纪元。
- **相同验证**：`verify:world-bible` 会一并扫描本目录；锚句字与主线锚句**逐字唯一**，
  任何重复都会令门变红（whoever 写新锚句，先确保不与主线撞句）。
- **UI**：本线不进入典籍室（`/bible`）书架——它不是正典，是正典的平行线（回响是侧写，本线也义）；
  想读的话直接读这里，markdown 原文与英译逐段对齐，遵守与正典同一纪律。

## 这是哪里来的

- 这条线与主线同源于第四章；它在另一条开发分支上生长（§cont. ~171 的某次并轨），
  被主线接手并存入本目录——**没有丢弃，也没有擅改一个字**（git 历史原样）。
- 章节与回响的真实性原物、原译文原样保存。主线与支线没有谁比谁更"对"——
  它们是同一座岛的两个方向。
