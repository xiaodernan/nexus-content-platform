## Scale

- Echoes: E02 through E36 — thirty-five entries, written against the same laws as the main line.

## Relationship to the main line

- **One shared constraint**: do not continue after chapter IV; everyone who asks is looking
  for the addressee; every echo happens after the Institute was founded.
- **Same verification**: `verify:world-bible` scans this directory too; its anchor sentences
  are byte-unique across the whole project — a repeat against the main line turns the gate red
  (anyone adding an anchor here must first check it against the main line).
- **UI**: this line is not listed in the 典籍室 (`/bible`) shelf — it is not the canon, it is the
  canon's parallel line (the echo is the other grain of the same stone); read it directly here,
  where the Chinese source and its English rendering sit side by side, subject to the same laws.

## Where it came from

- This line diverged from the main line at the end of chapter IV; it grew on the other
  development branch (§cont. ~171), and the main line inherited it into this directory —
  **nothing discarded, not a character rewritten** (git history preserved).
- Which line is more "correct" is no one's call — they are two bearings from the same island.

## Discipline

- Anchor sentences (`**锚句**` / `**Anchor sentence**`) are unique across the whole project.
- Two tracks: zh and en; a missing English track blocks the commit.
- Neither line may be rewritten into the other's wording — that is forbidden.
