## 为什么放在这里

- 编号冲突不能两边都进 `echoes/`：`gen-bible-snapshot.mts` 按文件名排序取 `NNN-` 前缀，
  同号两篇会让 digest、quiz、pind、锚句对齐校验各自产出说不清的结果。
- 正典字节级稳定前缀（§CACHE-4）——把任一套混进 digest 都立即令 provider KV 前缀失效，
  quire cache 与并行缓存的真机读数全部作废。
- `docs/world-bible/**` 的抓取器只看 `echoes/` 一层（`readdirSync` 不递归），所以 `lineages-alt/`
  下的东西天然不进产物；此目录**只存档不编辑**，除非某天做正式决策：把两套谱系合并成官方全集并重钉所有派生计数。
