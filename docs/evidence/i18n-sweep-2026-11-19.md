# §I18N-SWEEP · 静态双语残留扫描（2026-11-18 · 手写工具 `scratch/cjk-sweep.py`）

**背景**：用户长期要求「中文模式下零原生英文残留；英文模式下同理」——此前通过浏览器 EN 页面逐页 `cjk=0` 验证（见 v944-v961 记录）。

**方法**（本片补一刀静态扫描）：扫描 `apps/web/src/` 下 .tsx / .ts 中的所有 `en:` flag 块位置中出现 CJK 字符的行，过滤 `world-bible` 与 `node_modules`，76 suspicious spots 逐一归类。

**结论**：

| 归类 | 处数 | 判据是否可修 |
|---|---|---|
| 注释/doc-comments（理规允许，代码库统一为中文开发注释） | ≈ 50 | 不需要「统一翻英」 |
| kicker（如 `THE TIDE ORACLE · 潮语` / `ONBOARDING · 上手漫游`）— **刻意双语印刷** | ≈ 12 | 不需要翻译（kicker 约束相反） |
| `zh:` evidence 字符串（如 `insight-rules.ts`，zh 本就是中文） | ≈ 8 | 不需要修复 |
| en localeToggleHint = `切换到中文` / zh localeToggleHint = `Switch to English` | 4 | ✓ 已是双向翻译（correct pattern） |

**未发现**任何「密语」：EN 模板中夹杂原生中文按钮/文案/空白标签。

**下一步（可选）**：如果用户希望 `kicker` 也执行纯英文（English-only 铁律）而非双语印刷，请明令；当前采用「双语 kicker 印刷」与全站 100 个 commit 一致。
