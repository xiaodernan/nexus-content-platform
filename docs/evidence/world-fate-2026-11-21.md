# 新玩法「命运骰」实测（2026-11-21）

按钮：世界面板底部「掷命运骰」。纯函数 `rollFate(nodes, seed)` 从世界已有条目里抽两条，
用确定性句式重组成事件卡，感官细节优先取条目的记忆回声。**不调模型、不写库**——同一个 seed
同一张卡，换 seed 换一张，"无穷"来自作者已写细节的组合，不是编造。

真浏览器 E2E（Playwright）：

| 检查点 | 实测 |
|---|---|
| 连点两次的事件卡 | 不同（同一对条目、不同句式），`same: false` |
| 卡片内容 | 两条已写条目的标题与正文细节，无 `undefined` |
| 落库前后节点数 | 11 → 11（零写入） |
| pageerror | 0 |

脚本：`scratch/fate-e2e.mjs`。纯函数门 4 条（同 seed 可复现 / 换 seed 有变化且只引用已有 id / 跳过空壳 / 细节非空）。
