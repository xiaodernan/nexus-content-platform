# ADR 0316 · 教学说明只有一份真值，且每个操作都必须带它

日期：2026-11-23 · 状态：已采纳 · 关联：§HINT-1（`docs/ROADMAP.md`）、用户第五点
（「主界面给各种按键和操作加上附带的教学说明」）、
`apps/web/src/lib/hintCopy.ts`、`apps/web/test/hint-coverage-behavior.test.ts`、
`apps/web/src/studio/CommandBar.tsx`、`apps/web/src/studio/TopBar.tsx`、
`apps/web/src/components/CommandPalette.tsx`

## 背景

先用尺子量，再动手。静态扫六个主界面（首页 / 广场 / 观察站 / Studio 顶栏 / Studio 命令栏 /
命令面板）里的 `button` / `select` / `input`：

| 界面 | 带教学说明的控件 | 总数 |
|---|---|---|
| Studio 命令栏（`CommandBar.tsx`） | **0** | 14 |
| 命令面板（`CommandPalette.tsx`） | **0**（只有 `aria-label` 命名） | 1 |
| Studio 顶栏（`TopBar.tsx`） | 8 | 10 |
| 首页 / 广场 / 观察站 | 按钮全带；链接文字自明 | — |

命令栏那十四个控件是整个产品里最需要解释的一批，而它们一个说明都没有：
「执行」「Fast」「Balanced」「Reasoning」「让模型读一遍」「批准并交回编辑区」「放弃」
「取消这次作业」「展开计划」——「执行」和「批准并交回编辑区」对第一次进 Studio 的人
是完全等价的两个按钮：都按下之后画布上会出现变化，而**其中一个可能删掉东西**。

同时量到第二件事：**教学说明散在三份字典里**。命令栏的说明在它自己的 `COPY`，
顶栏的在 `shell-i18n.ts`，命令面板的又在它自己的 `CP_TXT_ZH/EN`。
同一个动作在说明书里叫「交给队列」、在界面上叫「异步作业」，用户得自己翻译；
而 §八 要求中文模式全中文、英文模式全英文——三份字典就意味着三处漏译风险。

## 选项

1. **各组件各写一句**（就地补丁）。改动最小，但真值仍然分散：今天三份，明天四份；
   门也只能查「有没有 title」，查不了「说得对不对、有没有漏译」。
   **否决**：它把「有说明」变成一件靠自觉的事，而自觉正是已经在漏的地方。
2. **做一个共享的 `<Hint>` 组件把控件包起来**（带气泡、`aria-describedby`、键盘可达）。
   交互最好，但本仓库的视觉门禁对组件里出现的类名有白名单
   （`command-bar-visual-style.test.ts` 只认 `.cb-`/`.sb-`/… 族），加一族新类名要改门禁契约；
   而且气泡样式受「零 `@media` / 零 `transition` / 零 hex」的约束，写不出好看的版本。
   **否决**（这一片不做）：先把「有说明」这件事做实，交互形态可以下一片再谈。
3. **一份教学说明字典 + 一道覆盖门**（采纳）。所有说明住在 `apps/web/src/lib/hintCopy.ts`，
   一条一个 id，中英各一份；控件用 `title={hint('<id>', locale)}` 取；
   门逐个控件查「有没有带说明、说明是不是出自字典、字典有没有死条目」。

## 决定

- **真值只有一份**：`@/lib/hintCopy`。这一片把原先散在 `CommandBar.COPY` 的五句
  （缓存徽章 / 车道徽章 / 异步 / 自查 / 点名）、`shell-i18n.ts` 的五句
  （面板开合 / 改名 / 主题模式 / 帮助 / 预览）全部搬进来，并补上原来根本没有的十一句。
  `shell-i18n.ts` 里那五个 key 已删除（确认过只有 `TopBar.tsx` 用到）。
- **一句说明要说后果，不说术语**：中文讲「按下去会发生什么」，英文同一句对应。
  短的、含糊的（「重命名项目」）改写成带后果的（「改完按 Enter 生效，按 Esc 取消」）。
- **豁免是声明**：文字自明的链接、带占位符的输入框不要求说明；
  三处**动态**说明（视口随断点宽度生成、撤销/重做由 store 现场给出）写在门的
  `DYNAMIC_EXCEPTIONS` 里，附理由，并且门会查每条豁免是否真的还在那个文件里——
  豁免不许变成永远用得上的借口。
- **门会抓到的坏形状**：说明不是出自字典的（手写内联字面量）、中英不齐、
  en 里混进汉字或全角标点、字典里有死条目、控件漏了说明。

## 后果

- **两处「剥 className 后全文零行为」的 SHA 门被有意打破并重钉**，来由写在门里而不是只换断言：
  `command-bar-visual-style.test.ts` `92aa97f3…` → `df3e44b5…`；
  `studio-topbar-visual-style.test.ts` `fabb39a2…` → `2f1ef1f9…`。
  理由：悬停能看到「按下去会发生什么」**就是**行为——这不是换皮。
- `ActivityFeed` 因此多收一个 `locale`（它的那颗「展开计划」按钮也要按当前界面语言给说明）。
- 门是离线的、纯静态的：不需要浏览器，不需要 provider，不花钱。
- **还没做的**：面板（属性 / 图层 / 资产 / 故事板 / 角色…）里的按钮仍然各写各的 `title`，
  没并进字典；`hintCopy` 目前只覆盖 Studio 外壳与命令栏。下一片要么把面板搬进来，
  要么先做 §选项 2 那种共享气泡组件。门现在只对已覆盖的六个界面负责，不假装全站覆盖。

## 证据

- 门：`apps/web/test/hint-coverage-behavior.test.ts`，5 臂全绿（字典 / 接线 / 覆盖 / 豁免 / 非内联）。
- 变异验伪（每处只红该红的那条臂，已还原）：
  ① 删掉「执行」那颗钮的 title → 「覆盖」臂红；
  ② 英文说明里塞一个汉字 → 「字典」臂红；
  ③ 源码引用一个字典里没有的 id → 「接线」臂红；
  ④ 字典里加一条没人用的说明 → 「接线」臂红。
- `tsc -p apps/web/tsconfig.json --noEmit` 退出 0；
  `vitest` 相关六文件 56 项全绿（新增的门 + 命令栏 / 顶栏 / 命令面板视觉门 + 两条 i18n 门）。
