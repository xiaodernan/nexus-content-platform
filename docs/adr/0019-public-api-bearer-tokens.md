# ADR-0019：公开 API 用「哈希存储的 Bearer 凭据 + 两格 scope」，不复用会话 cookie

日期：2026-09-28 ｜ 状态：已采纳（第一片，只读） ｜ 关联：§188（MCP / 外部 Agent / 公开 API）、§80、§74、§159、§16、§68

## 背景

M8 要求平台外部的调用方（MCP server、CI 脚本、第三方 Agent）能读到项目的设计文档。
仓库里已有的鉴权只有一种：`nexus_session` 会话 cookie，由中间件签发、`requireUser` 消费，
配套 CSRF 双提交保护状态变更。cookie 这套东西是为「浏览器里的人」设计的，直接拿来给外部调用方用会同时踩三个坑：
凭据会被自动带上（CSRF 的前提）、会随浏览器会话一起过期（CI 跑一次不该有「会话」）、
以及无法按调用方划分能读什么。

## 选项

1. **复用会话 cookie**，外部调用方贴 cookie 进来。省事，但上面三个坑一个都不解决，
   而且等于宣布「平台的 API 凭据就是会话」——一次泄露即一次账号沦陷。
2. **签 JWT 无状态令牌**。服务端不必查库，但随之而来的吊销问题是硬的：
   要做到「吊销即失效」就得引入拒绝列表，那本质上又回到有一张表。
3. **不透明随机串 + 库内哈希**（本决定）。与 `sessions` 同一口径（§80：库里从不存明文），
   每次调用查一行，吊销即生效，签发与吊销都有账可查。

## 决定

- 表 `api_tokens`（迁移 0018）：`token_hash` 存 SHA-256，唯一索引建在哈希上；`hint` 只留随机段前 8 位用于在列表里认哪一把；
  `revoked_at` 用时间戳而不是布尔，行不删；`user_id` 上 `ON DELETE CASCADE`（人注销，凭据跟着没）。
  `scopes` 用 text[] + CHECK 而不是 pg enum，与 §133 的 `users.plan` 同一个理由：加一格只改约束，不重建类型。
- 明文前缀 `nexus_pat_`，随机段 32 字节十六进制。鉴权时先按前缀分流，
  所以「有人把会话 cookie 当 API 凭据用」这件事能报出准确的那一句，而不是「鉴权失败」。
- 所有 v1 端点只经 `authorizeApiRequest`：Bearer 解析 → 鉴权 → scope → 每凭据每分钟限流。
  路由里不许自己重复这几步——§74 的教训是「一条路管一条路，就等于两条路各有一套规矩」。
- scope 名单只有两格（`projects:read` / `design:read`），因为今天只有两个真端点执行它们。
  名单在 `@nexus/schemas` 的 `API_TOKEN_SCOPES`，库里的 CHECK 与端点里的实际调用是同一件事的三处写法，
  由 `apps/web/test/api-tokens.test.ts` 交叉比对（三处不一致就红）。
- `last_used_at` 写入按分钟节流：一个读接口不该因为「想知道谁在用」而变成写接口。
  界面上这一列因此标成「最近使用（分钟级）」。
- v1 没有写端点。`/api-tokens` 页面上「POST 到这里是 405，那是写还没做而不是写被禁用」这一句
  由测试钉住（每个 v1 路由只导出 GET）。

## 后果

- 好处：吊销立刻生效且可解释（401 带着吊销时间）；凭据可按调用方发、按调用方撤；
  读路径与浏览器会话彻底分开，CSRF 的适用范围也写清楚了（cookie 会话内的状态变更仍要 CSRF，
  见 `/api/account/api-tokens` 的 POST；Bearer 只读端点不需要）。
- 代价：每次调用一行 SELECT（限流在前，量级可控）；明文一次性显示，丢了只能重发——
  这一点必须在界面上说清楚，否则用户会以为「刷新一下还能看到」。
- 已知限制（下一片要接的）：设计文档整份返回、没有分页也没有字段裁剪，4000 节点档的项目会给出很大的响应；
  没有 `projects:write` 之类的写 scope；还没做凭据级的读审计（现在只有 `last_used_at` 那一个分钟级的信号）。
- 未验证（下一片）：**写路径**还没有任何端点，所以外部 Agent 今天只能读不能改；凭据级的读审计只到 `last_used_at`
  那一个分钟级信号，没有"哪一枚凭据在什么时候读了哪一份文档"的流水。
  界面那一寸已在真浏览器里点过：`e2e/api-tokens.spec.ts` 两条 @smoke（签发 → 页内真 fetch 200 → 缺 scope 403 →
  吊销后 401 → 刷新后整页找不到明文；外加游客不可达），截图两张 `screenshots/api-tokens-issued.png` /
  `screenshots/api-tokens-after-reload.png`。
