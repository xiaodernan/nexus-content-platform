# ADR-0298 · 万象脉络：用图算法把世界投影成权力骨架（2026-11-21）

## 状态
已接受（2026-11-21 · cont.474 · 纯函数判据 14 条 + 页面门 8 条）

## 背景

用户的核心目标是一个"宏观史诗叙事 + 细节包罗万象"的庞大世界。世界线已有十几个视图
（编年 / 星图 / 星历 / 地理 / 典籍 / 速览 / 潮汐…），但没有一个视图回答**结构性问题**：
谁是这个世界的权力中心？哪几条关系是"一断全散"的关节？哪些条目互相纠缠成势力团？

`WorldDocument` 有真实的九类 `nodes[]` 与有向 `links[]`，但关系只被当成星图上的线看，
没被当成图来算。用户也明确要求"用数据结构与算法分析优化项目"——这一片正好落在这里。

## 决定

新增纯函数 `lib/worldNetwork.ts`（零写库/零 provider）+ RSC 页面 `/world/[projectId]/network`：

- **枢纽榜**：入度（被多少关系指向）+ 出度（指向多少人），按和降序、平局用 in/id 兜底；
- **势力团**：Kosaraju 强连通分量（O(V+E)），互相可达的一簇就是一团；
- **关节（割边）**：Tarjan lowlink，删掉它无向连通分量 +1——叙事上"一断全散"的线；
- **跨类关系**：按 label 聚合不同 kind 的边，同类边不进这张表；
- **孤立条目**：无任何关系的节点如实列出，不藏。

算法全用**迭代 DFS / 并查集**而非递归：一个史诗世界可能有上万节点，递归会爆栈（OS 层的现实约束）。
所有平局用 id 字典序兜底，同输入永远同输出。

## 路上抓到的真 bug

第一版 Tarjan 桥按**父节点名**跳过父边：`a→b` 与 `b→a` 两条边时，第二条被当成普通回边漏掉，
于是把本该成环的 a-b 误判成桥。变异测试（去掉父边跳过）让 4 条判据变红，反证了判据有牙。
修法：邻接表按**边**（带唯一 edgeId）存，DFS 只跳过那一条父边本身，不跳过同端的其它边。
这是图论教科书里"多重边要按边而非顶点处理"的那一格——写成代码才踩到。

## 诚实边界

- 世界读不出来 ⇒ `data-network-empty` 页不画任何数字；空枢纽/势力团/桥/跨类各自如实空白；
- 自环与悬空边（端点不在节点表）不进骨架，与 `validateWorld` 口径一致；
- 单点分量不算"强连通"（自环已排除），如实标弱；
- 作者可见（requireUser + projectVisibleTo + notFound），零 provider、零写库；
- 本轮数据库 `nexus-postgres` WAL 损坏 shutdown，页面浏览器层未截图验证（如实记，不假造）。

  Kosaraju 势力团、跨类聚合、确定性双跑、2000 节点长链不爆栈。
- `network-visual-style.test.ts` 8 条：RSC + 权限 + 零 provider、空态、data 钩子、

- 变异臂：按顶点跳过父边 → 4 条变红（已修）。
- digest 视觉门重钉：页脚加「万象脉络 →」入口（`data-digest-open-network` + 双语文案），
  真实新导航元素，旧 SHA `1cfae46a…` → 新 `cfb5e1af…`，理由写进门里。

## 补记（2026-11-22）· 割点：与割边互补的那一格

- 第一版只有**割边**（bridge）：删一条关系会分家。但"删一个**条目**会分家"是另一种性质：
  三角形的一个角，两条边都在环里（都不是桥），这个角本身却是割点吗？——不是；
  而一条链的中间点，它每条边都是桥，它自己也是割点。两者相关但不等价。
- 新增 `cutVertices: { id, degree, parts }[]`：迭代 Tarjan，父边按 **edge id** 跳过
  （重边/双向边不会漏），`parts` 由 DFS 直接算——非根 = 分离子树数 + 1（父侧），
  根 = 子树数。**根不能用 separated 套**：根的每个子树都会让 separated 自增，
  一条链的根会被误报成 parts=2（写测试时抓到的第一版错误）。
- 判据 8 条：链/三角形/星形/两团相连/重边/2000 节点长链/确定性；页面新增全宽
  「关节（割点）」面板，真实世界读数 6 个割点（潮候院、沈砚各裂 3 块），390 宽 0 溢出。
