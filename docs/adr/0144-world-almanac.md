# ADR 0144 — 世界藏经阁：世界子系统的卷首与目录

- 状态：ACCEPTED（2026-11-14）
- 范围：世界子系统（`/world/<projectId>/almanac`）
- 前置：v704 (ADR 0135)、v705 (ADR 0136)、v706 (ADR 0137)、v708 (ADR 0141)、v709 (ADR 0142)、v710 (ADR 0143)

## 背景

世界子系统长到了六个入口：步行、星图、编年、回廊、图志，再加上 Studio 顶栏的一排链接。
没有一个"殿门"——新访客（和三个月后的自己）不知道先推开哪扇门。编年是时间、图志是空间、
回廊是记忆、星图是人物：它们缺的是同一本目录。用户要的是"宏观的史诗叙事"——
史诗没有目录就不是结构，只是堆砌。

## 决定

1. **「世界藏经阁」是一页纯投影的卷首**：零写库、零 schema 变更、纪元顺序与编年同一口径
   （`buildChronicle` 直复用）、人物普查直取 `listCharacters`（`.catch` 退化为空名单 + 读不出计数，
   不凑数）。
2. **结构与视觉语言**：夜金（`#c9a86a`）+ 墨底（`#05070f`）+ 衬线大字（Noto Serif SC 栈，
   无外部字体依赖）。三块信息：卷首（世界名 / 卷语 / 统计行 / 最长 memory 回声作题词）、
   纪元长卷（按纪元排序的徽章链）、四卷殿门（卷一编年 / 卷二图志 / 卷三回廊 / 卷四星图，
   数字作背景水印 bleed）、世界九造·条目普查（九类计数横条，按 max 归一）。
3. **入口纪律**：Studio 顶栏「世界藏经阁」链接（data-enter-almanac）+ 图志头部交叉链接；
   可见性与其他世界页同（`projectVisibleTo`，未授权 404）；读不到就说读不到（无世界 = 空态）。
4. **不做的**：不在这页做任何交互状态、不自动播放、不生成内容、不发布——发布模型不动。

## 仍欠（诚实记录）

1. 纪元徽章链目前不带 `#era` 锚点（编年页尚未给纪元段落加 id）；加锚点是编年页的一次独立评审。
2. 题词取"最长两条 memory"（按字符数），不是随机轮换——静态 SSR 优先于花哨。
3. 藏经阁页不进 Studio 主导航的一级 tab（Studio 是工具，藏经阁是卷首）；
   若日后要加，需要导航评审。
