# ADR-0074：公开页默认按访客视口自动选档——四份投影 + 媒体查询

## 背景

ADR-0069 给公开页接了 `?viewport=`，但它只是**手动**那一半：访客不点链接时，页面仍按设计尺寸
（1440）投影。第十三片量的原始事实因此一直在：390 宽的手机上帧是 1440，要横向平移 **1082px**，
首屏只看得到 **27%**。第二十五片复跑确认这不是测量偏差——是不点参数就没人替访客选档。

这一片要还的就是那一格：**默认（不带任何参数）时，访客看到适合自己视口的那一版**。

## 选项

1. **服务端从 UA / Client Hints 猜视口宽**：CSS 不能拿长度除长度，服务端也拿不到真实视口宽；
   Client Hints 只有 Chromium 系、UA 在缩放/折叠屏/平板模式下都不可靠。猜错比不猜更糟
   （给 1024 的平板发 mobile 版）。
2. **客户端 JS 量 `innerWidth` 再跳转/重渲染**：多一条渲染路径，首屏先闪一下错的版本，
   禁用 JS 的访客直接拿不到；还会改写地址栏，破坏"同一个 URL 同一份内容"。
3. **服务端把四档各解一份铺进 DOM，用媒体查询选一份**：零 JS，媒体查询就是浏览器自己的
   视口判定；四份来自同一个 `resolveLayout`，只是 `breakpoint` 不同——不是第二条渲染路径。选定。

## 决定

- **只在作者真的写过断点规则时启用**（`hasResponsiveRules(page)`）：没有规则时四档的差别只是
  根画框宽度，内容仍按绝对坐标摆着，自动切换只会把画面裁掉。这类页面**默认输出一个字节都不变**，
  仍是单份设计尺寸投影（sitemap 里绝大多数页面属于这一类）。
- **参数语义**（`publishedViewportFromParam`）：不写 / `auto` = 自动；`design` = 钉住设计尺寸；
  四个断点名 = 钉住那一档；认不出来的值退回 `auto`（ADR-0063：降级，不 404）。
- **区间从模型推**（`publishedVariantsStyle`）：基规则 `[data-published-variant]{display:none}`，
  再按 `BREAKPOINT_WIDTH` 出四段 `@media`：mobile 0–767、tablet 768–1279、desktop 1280–1535、
  wide 1536+。界面不另抄一份数字；换档点由单元测试逐宽度求值证明"无缺口、无重叠"。
- **一份投影一个组件**（`PublishedFrame`）：缩放盒、状态差量样式表、节点、热点都收在一处，
  四份只有 `layout` 不同。热点按各自 layout 重算——四档的坐标不同，不能共用一份。
- **隐藏的变体是 `display:none`**：不占位、不进可访问树，于是 Tab 序与读屏只会遇到一份。
- **控件行只摆真的会变的按钮**（§159）：没有规则的页面不出现「自动」；有规则时「设计」
  链到 `?viewport=design`，否则链回无参数。钉住某一档时 `data-published-variant` 写那一档的名字，
  不冒充 `design`——断点门靠这个属性读数，标签不能撒谎。

## 后果

- **规则页**：390 → mobile（375，0 平移）、768 → tablet、1280 → desktop、1536 → wide；
  隐藏三份 `display:none`。HTML 里因此有四份帧（夹具页约 3KB → 12KB 量级），这是零 JS 的代价，
  只落在真有规则的页面上。
- **无规则页**：单份、1440、无 `data-published-auto`，与这一片之前逐字节一致。
- **读数**（`e2e/viewer-breakpoint.spec.ts` 3 tests / `e2e/mobile-layout.spec.ts` 1 test 全绿）：
  sitemap 五张里那张有规则的夹具页在 390 下从 **1440 宽 / 要平移 1082px** 变成 **375 宽 / 0 px**；
  其余四张（无规则）原样 1440 / 1066px。
- **三条臂**：去掉注入的媒体查询样式 → 四份全显示，门红在"另外三份必须 display:none"；
  去掉 `hasResponsiveRules` 闸 → 无规则页也铺四份，门红在"没有规则的一页只解一份"；
  中段区间上界少减 1 → 768 同时落进两份，单元测试的逐宽度求值红。
- **仍欠**：1024–1279 这一带没有单独读数（区间已覆盖，未量真机）；iOS Safari 真机与手势未量；
  断点规则本身的**作者侧编辑**是另一条线（`responsive-editor.ts`），与本决策无关。
