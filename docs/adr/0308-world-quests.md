# ADR 0308 · 世界委托：把「今天该做什么」从一张指标表变成可执行的委托板

- 日期：2026-11-22
- 状态：已采纳
- 相关：§WORLD-NET（割点/孤岛）、§v719-Tide（真值投影）、§FE-IC（世界体检）、ADR 0262（没报 ≠ 0）

## 背景

世界线已经有 `/integrity`（全部指标摊开）与 `/network`（图算法骨架），但两者回答的是
「这个世界现在是什么样」，不回答「我今天先做哪一件」。

用户总指令要求「足够充分的引导，防止迷失」与「辽阔的土地上要有足够多细节可探索」。
把体检单再复制一份不够——数字重新排版不会让人动手；要的是**从真实缺口里长出任务**，
且任务完成后必须真的从板上消失，不能有假进度条或假积分。

## 决定

1. **纯函数层 `lib/worldQuests.ts`**：把 `WorldDocument` + `Character[]` 投影成八类委托
   （空页 / 薄节点 / 未标纪元 / 序号撞号 / 未解析关系 / 孤岛 / 关节 / 缺色板）。
   数字与 `/integrity` **同口径**：未标纪元走 `buildChronicle` 的归一化，孤岛/关节走
   `buildWorldNetwork` 的 Tarjan 结果，未解析关系走 `buildConstellation`——两页永远不会互相矛盾。
2. **「今日三件」用确定性轮转，不用随机**：`FNV-1a(projectId + 日期(UTC+8)) % open.length`
   决定起点，取前三。同一天同一世界永远同一组；跨天自然换一批。没有 `Math.random`，
   没有服务端时钟漂移（日期键固定 UTC+8）。
3. **三态而不是两态**：`open`（有缺口）、`closed`（曾经适用、现在计数为 0）、`notStarted`
   （对象还不存在，例如还没有人物）。没有人物时不把「缺色板」报成「已完成」——
   那正是 ADR 0262「没报 ≠ 0」的同一形状。
4. **每张卡自带三步怎么做 + 真实样例（最多 3 条）**：链接直达最适操作面（设定集 / 编年 /
   星图 / 万象脉络 / Studio），样例只列真标题或「谁 → 谁」，不生成占位内容。
5. **空世界先教落第一条**：`emptyWorld` 时不画「8 项全部完成」，而是给一条去 Studio 的引导。
   世界读不出来则如实空白，零数字。
6. **双语 + 门面样式**：zh/en 两套字典完整覆盖八类委托；`.wq-*` 全部 token 化、
   forced-colors 收口、720px 以下单列。

## 后果

- 新页面 `/world/<projectId>/quests`，从 `/integrity` 与 `/digest` 页脚各有一个双语入口；
  `/guide` 的世界功能地图两侧同步补行。
- 判据：`world-quests.test.ts` 10 条（空世界不假完成、三类计数、撞号只数多余行、
  未解析标签、孤岛/关节来自真算法、色板适用性、focus+rest=open、同日稳定/跨日轮转、
  UTC+8 日期键、FNV 稳定）；`quests-visual-style.test.ts` 8 条（RSC/仅作者/零 provider/
  零写库/零随机、空世界引导、钩子守恒、类族、定义与 forced-colors、零 hex + token 声明、
  双语八类齐全、SHA 钉死）。
- 导航变更按惯例重钉：`integrity-visual-style` 与 `digest-visual-style` 的 SHA 各更新一次
  （真实新增入口，不是换皮）。

## 诚实边界

- 本片没有浏览器像素验收（本机未起 3100 前端）；样式正确性由 token 纪律与门面判据保证，
  「看起来如何」留给下一次带浏览器的窗口。
- 「今日」是**选择顺序**，不是奖励：没有连击、没有积分、没有排行榜。委托完成只体现为
  真实计数下降，`closed` 也只说「现在计数为零」，不说「你赢了」。
- 八类缺口是当前世界模型能测的全部，不是「世界的全部玩法」；新缺口类型应先在
  `worldQuests.ts` 里定义可测对象，再加卡，不在页面上直接写数字。
