# ADR 0145 — 谜灯馆：世界文档自己当题库的"点灯试炼"

- 状态：ACCEPTED（2026-11-14）
- 范围：世界子系统（`/world/<projectId>/quiz`，v717）、`apps/web/src/lib/quiz.ts`
- 前置：v705/0136（chronicle）、v708/0141（memories）、v709/0142（atlas）、v711/0144（almanac）

## 背景

五个世界表面都是"只读投影"——站着看、走着看、读着看。用户要求"新的玩法"。本 ADR 回答一个具体问题：
**在不引入写库、不引入假数据、不改变可见性模型的前提下，世界文档里有没有可以玩的内容？**
答案：有——它自己就是题库。每条带 `memory` 的历史/故事都是一枚点灯锦囊；纪元名是唯一答案。

## 决定

1. **两档题族，全部题面/选项出自世界文档**（零编造）：
   A. 回声的归属：题干是 `lore.memory` 原文，问它属于哪个纪元（选项池 = 本文档出现过的纪元 ∪ 未标纪元，
      池内去重后恰好 ≥4 才出此题，否则宁缺毋滥）；
   B. 条目的名字：题干是 body 节选（≥8 字），问它叫什么（选项 = 另 3 个 story/history 标题）。
2. **同一条目只占一盏灯**：A、B 两族候选并集后按 source id 去重——灯廊不虚胖、不公平挤占。
3. **确定性**：PRNG = mulberry32(FNV-1a 变体 `seedFromString`)。种子 = `seedFromString(worldId) ^ 0x1e3779b9`；
   "再来一局"在客户端以 `Date.now()` 重掷——页面给出的题组同种子同输入同输出（与编年同一口径）。
   上限 8 题（A≤4、B≤4），不足就少出；一个也出不了就返回空组，空态交给 UI。
4. **零持久化、零写库**：对/错、得分、回顾列表全部客户端 state；不记成绩、不记尝试次数；
   尝试答案刷新即重置——世界文档是本殿唯一的残卷。
5. **判词（`verdictFor`）**：0/⅛/¼/… 分级（无灯/初来乍到/一枚灯芯/半盏灯/整船灯芯/灯海），
   全部与得分比例挂勾，不与"认识多少字"挂勾。
6. **可见性同纪律**：`requireUser` + `projectVisibleTo`，未授权 404；不是公共游戏。
7. **入口纪律**：Studio 顶栏「谜灯馆」（data-enter-quiz）、藏经阁第五门「卷五 · 谜灯馆」（题数动态）、
   图志/回廊/编年四个共享导航行各追加「谜灯馆」chip；constellation（h-dvh 视口）不放 chip。

## 仍欠（诚实记录）

1. **no persistence**：不记成绩 = 没法做错题本/排行榜/每日挑战——魅力功能，不是缺陷；加它需要新写路径与隐私评审。
2. **A 族在单/双纪元世界缺省**：池 < 4 宁缺毋滥，宁可少出题。fixture 有 3 纪元+未标纪元 → 恰好可玩。
3. **题面节选 `body.slice(0,140)`**：长 body 只显示前 140 字，题干不会泄露答案，但也不会出全文。
4. **世界步行（walk）页面不放 chip**：h-dvh 3D 视口不塞工具条。
5. 无音频、无动画库：灯廊 "current" 用 CSS animate-pulse 单一节奏，克制是刻意的。
