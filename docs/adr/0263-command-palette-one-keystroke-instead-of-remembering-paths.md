# ADR-0263：全站命令面板——一次按键换掉"记路径"这件事

- 状态：已采纳（2026-11-13）
- 关联：`docs/adr/0109-design-system-css-layer-gates-and-motion-contract.md`（`.cp-*` 走同一套门面纪律）、`docs/adr/0178-*`（门面类零裸原子）、`apps/web/src/lib/keyboard.ts`（"焦点在输入控件里，键入属于用户"）、`apps/web/src/lib/command-palette/*`、`apps/web/src/components/CommandPalette.tsx`
- 触发：用户长期点名「开发一些会饱受用户喜爱的新功能」「把前端做的特别漂亮」「注意前后端的协同发展」

## 起因：路由长到"记不住"，而记不住就是不用

这个产品的路由已经到 36 张页（其中管理台 14 张）。从 `/credits` 想去
`/marketplace/earnings`，今天只有两条路：**记住路径**，或者回首页点两下。
第二条路要经过一次与目的无关的首页渲染——那是一次纯损耗。

命令面板把「我记得有那么个页面」压成一次按键 + 三个字符。这类控件（VS Code / Linear /
GitHub / Raycast）之所以被用户喜欢，不是因为酷，是因为**它把"找"从线性扫描变成一次输入**。

## 决定

### 1）自己写匹配器，不引模糊搜索库

候选集是**我们自己的命令表**（16 条），不是用户的任意数据。引 fzf 移植版或 Fuse.js 会同时
买进三样不需要的东西：几 KB bundle、一套解释不了的分数、以及"调不出结果时不知道为什么"的黑箱。
本片只有一条判据：**字符必须按顺序出现，且分数要能一眼看出为什么高**。

算法（`command-palette/score.ts`）：两趟贪心，取分高者。

- 单趟「最左优先」有一个众所周知的坏例子：查询 `ab`、标题 `a_x_ab` → 拿 `a(0) b(5)`，
  丢掉 `ab` 连续命中的加成，把一条本该排前的候选择到后面；
- 反过来「最右优先」会把 `ab_x_ab` 拿成尾部那对，丢掉「从开头命中」的加成；
- 所以**两趟都跑**（正扫 + 反扫），按分数取优，同分取正扫。

代价是 2×O(n·m)。n 是用户刚敲的几个字符，m 是标题长度（十几），C 是命令数（16）——
键盘每敲一次全量重算，实测远低于一帧预算。**故意不做前缀树/增量索引**：为 C=16 建树是
拿复杂度换不存在的性能（ADR-0104 的"摊还复杂度要能算出来"反过来用）。

分数构成全部是整数、可复算、写进判据：命中 `+10`／词边界 `+12`／相邻 `+14`／
整条前缀 `+40`／首个命中落词边界 `+22`／空隙 `×2` 最多扣 `24`。

### 2）CJK 不假装有词边界

中文标题没有"词边界"。`isBoundary` 对它们基本返回 false，于是中文命令只吃
命中分 + 连续分 + 前缀分。这是**如实的结果而不是补偿**——对一个中文标题假装有词边界，
只会让排序变成玄学。CJK 也没有大小写，`toLowerCase` 对它是恒等变换。

### 3）管理台路径**不进**命令表

`/admin/*` 是内部拓扑。写进命令表等于把"我们有哪些运维面"编进**公开的客户端 bundle**——
任何人下载 JS 都能读到，而管理台本身是 `role=admin` 才进得去。本仓对这条边界的口径
一路下来都是「不外泄内部读数」，命令面板没有理由例外。

**代价如实记**：管理员少了一个「⌘K 直接跳死信巡检」的便利。换的是
"客户端 bundle 不成为权限地图"。判据 `command-palette-registry.test.ts` 里有一条
`href.startsWith('/admin') === false` 守着它，防止某次"顺手加个快捷入口"悄悄破掉。

### 4）画布页不挂胶囊，但热键照旧

胶囊是左下角的 `position: fixed` 浮层。Studio / 游戏 / 3D 世界 / 预览这四类页面
左下角是**工具位**（缩放、状态条、视图控件），压上去就是挡住真实操作；右下角已经被
主题按钮占了，没有第二个角。所以 `placement.ts` 按**路径段边界**（不是裸 `startsWith`，
`/studio-notes` 不受影响）判"这一页挂不挂"。

**热键与路由无关**——⌘K 在画布页照样开。少掉的只是"看得见的提示"。
代价：第一次进 Studio 的人不会知道有面板；但 Studio 自己有 CommandBar 承担同一职责。

### 5）只让输入框可聚焦（WAI-ARIA combobox + listbox）

高亮由 `aria-activedescendant` 表达，焦点始终在输入框。好处是**不存在焦点陷阱要维护**——
整个对话框只有一个可聚焦元素，Tab 就地吃掉即可。代价是列表行不能单独 Tab 到
（读屏仍会念，因为 activedescendant 指过去了），这是这种控件的标准取舍。

### 6）纯 Ctrl+K 在输入框里放手，⌘K 例外

Emacs 键位（macOS 文本框、不少 Linux 输入框）把 Ctrl+K 定义成"删到行尾"。网页抢走它
等于在用户正在打字时删他的字——这是 `lib/keyboard.ts` 那条纪律的直接推论。
但 ⌘K 在 macOS 文本控件里没有原生含义，而"正在写东西时想跳走"恰恰是面板最常见的用法，
所以它照开。判据在 `input.ts` 的 `isPaletteHotkey`，四条各有理由。

### 7）最近使用只存 id，不存查询串

`localStorage` 存最近用过的 8 个 command id，只用于**同分时加权**（`+6`），不改变匹配与否。
有界、失败静默。**不存查询串**——用户敲过什么可能包含项目名，那是内容不是偏好。

## 仍欠（如实记）

1. **没有真浏览器读数**：e2e 未跑（`data-command-palette-*` 钩子已备好）；
   hover 态与 390 下的实际占位没有截图。
2. **没有项目级跳转**：Studio / 项目页要 `projectId`，写死假 id 只会 404，
   做成"先选项目"的中间态又会出现没有终点的入口。要接得先有"最近项目"接口（另立）。
3. **结果集没有虚拟化**：上限 40 条、单条 36px，最坏 1440px 的滚动内容。命令数涨到三位数
   才需要虚拟列表；现在做是拿复杂度换不存在的性能。
4. **最近使用不跨设备**（`localStorage`），且不区分用户——同一台机器上换账号会共用。
   要修得先有账户级偏好存储。
5. **未 push**（约定）。
