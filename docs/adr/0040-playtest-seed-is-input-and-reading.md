# ADR-0040：随机种子是报告的入参，也是报告的一部分——界面上那个数字只许来自 `report.seed`

- 状态：已采纳（§53 试玩报告的第二片：把限度里那句"换种子就是换一次抽样"变成做得到的事）
- 日期：2026-10-15
- 关联：§53、§16、§159、ADR-0039（同一批链上格子的口径）、`packages/game-model/src/playtest.ts`、`apps/web/src/game2d/{GamePlay,RpgPlay}.tsx`

## 背景

§53 那份"自动跑一遍"的报告有三条限度，第二条写着：

> 随机游走用的是定种子（默认 7），所以同一份设计两次报告逐字段相同；**换种子就是换一次抽样**，不是换一套规则。

这句话在 2026-10-15 之前是**做不到的**：`playtest()` 里没有种子这个入参，四个走法永远吃同一个常量。
于是界面上出现了一类 §159 禁止的话——限度教作者"你可以换一次抽样看看稳不稳"，
而页面上没有任何地方能换。作者照那句话去做，会发现只能反复点同一个按钮，得到逐字段相同的报告，
然后怀疑这四种走法根本是同一份脚本。

同时有两个约束收紧：

1. **§16 只有一处真值**。两个试玩面板（2D 与 RPG）都要有这一个控件，
   校验规则若各写一遍，就会出现"这一页允许、那一页悄悄回落到默认"的分叉。
2. **报告说了什么，就得是什么**。输入框里是 11、实际跑了 7，界面上印 11 就是谎；
   输入被清空拿到 `NaN`，LCG 会把整份报告算成 `NaN`，那比谎更糟——它看起来像一份真读数。

## 选项

1. **把限度里那半句删掉**（改成"种子固定，不可更换"）。否：
   那句话本身是真的（定种子确实让报告可复现），删掉是把已经说清楚的东西改回含糊，
   而且放弃的是这份报告唯一能回答"这版是不是只在某一次抽样下能通"的手段。
2. **在两个面板各写一份输入校验**（`Number.isFinite` 不通过就当 7）。否：
   两份校验就是两份真值（§16），更要紧的是它管不住界面印出来的那个数——
   面板很容易顺手把 `seed` 这个 state 直接显示出去，而它恰恰不是"实际用的那个"。
3. **种子进模型层做入参，报告把实际用的那个数带回来**（选定）：
   `playtest(plan, policies?, seed?)` / `playtestRpg(...)` 同形状收 seed，
   `effectiveSeed()` 是全仓唯一一处回落规则（非有限值 → 默认；小数**取整**而不是四舍五入，
   因为 `12.7` 与 `13` 是两份不同的抽样），而 `PlaytestReport.seed` 是**必填读数**：
   它说的是"这一份报告跑了哪个种子"，不是"输入框里现在有什么"。
   界面因此没有第二种可显示的数——`data-playtest-seed-used={report.seed}` 与
   `playtestSeedNote(report.seed)` 都吃报告，控件的 `value` 只是作者下一步想用的数。

## 决定与后果

- **限度文案由常量插值**：`PLAYTEST_BASE_LIMITS` 第二句里的"默认 7"来自 `PLAYTEST_DEFAULT_SEED`。
  换默认值时文案跟着走，不会出现"文案说 7、行为用 12"。测试把那句话里的数字**抠出来**与
  `report.seed` 比，而不是与手写的 7 比——这样它测的是"文案与行为是否同一处"。
- **只有随机游走那条吃随机数**，所以换种子时 `idle` / `beeline` / `flee` 三条必须逐字段不变。
  这条性质双向钉住：三条不变 + `wander` 的终点必须变。只钉前一半，等于允许"种子根本没参与"。
- **`playtestSeedNote()` 收在模型层**，两个面板共用一句"就是默认那一个"与"不是默认的 7：换一次抽样"。
  两种说法互斥（各自 `not.toContain` 对方那半句），否则一句可以冒充另一句。
- **对话管线没有这个控件**，因为 `playtestStory` 没有随机成分——那里查的是引用图的可达性，
  没有"抽样"可换。这不是遗漏，是那条管线今天没有可复现性问题要回答。
- **代价**：报告类型多一个必填字段，所有整份比较报告的用例要一起带上它（报告是包内对象，
  没有跨端 zod 合同，所以不牵动 `packages/schemas`）。
- **未做**（留作下一步）：把这份报告接进 §52 那条编排链（#137）。那一格同样确定性、同样不留草稿，
  种子也该由作业入参带进来，而不是在链里再藏一个常量。
