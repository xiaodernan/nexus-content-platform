# 0085 - 1280 的画布悬崖：属性栏可折起，而不是把 xl 门槛往后挪

日期：2026-11-05

## 背景

第四十五片量到：1279 与 1280 只差 1px，Studio 的画布可用宽度从 **971 掉到 672**。
根因不是左栏，是右侧属性面板：`<xl` 时它是 52vh 的底部浮层，`xl:` 起变成 300px 的常驻内联列
（`StudioShell` 的 `max-xl:block` / `xl:static`）。

于是 1280–1439 的笔记本用户只有一个选择：接受画布少 21 个点，换一块常驻属性栏。

## 选项

1. **把内联门槛从 xl(1280) 抬到 2xl(1536)**：1280–1439 回到浮层属性栏、画布保住 971。
   但这会让最需要常驻属性栏的那批机器（1280 笔记本）失去它——等于用一半人的习惯换另一半人的画布。
2. **属性栏可折叠，默认不折**：常驻仍是默认（既有行为一个字不变），需要的作者自己点「折起」，
   画布立刻拿回 300px。**选定。**
3. 什么都不做，只把悬崖写进文档。第四十五片已经这么记过一次；这一片把它变成选择。

## 决定

- `StudioShell` 新增 `inspectorFolded`，默认 `false`。
- 折起时：`aside` 加 `xl:hidden`（`<xl` 的底部浮层行为不变），右缘出现一个竖排「属性」标签
  （`[data-inspector-unfold]`，垂直居中，`min-h-8 min-w-8`）；展开时标签消失，面板里的
  「折起」按钮（`[data-inspector-fold]`，`xl:inline-flex`，但只在 xl 显示）拿回焦点。
- **焦点跟着走**：折起后焦点落在「属性」上，展开后落在「折起」上（`requestAnimationFrame`
  等这次渲染落地再 `focus()`）——不能把键盘用户留在被 `hidden` 的按钮里。
- **不持久化**：刷新回到默认展开。折叠是"此刻想让画布大一点"的临时选择，不是项目设置；
  真要记住，得先决定它属于作者偏好还是这台设备偏好（那是账户/本地存储层的决定）。
- **不改门槛**：`xl` 仍是 1280。默认布局与所有既有读数保持一致。

## 后果

- 1280×900 与 1440×900 实测（`e2e/studio-inspector-fold.spec.ts`，1 passed / 17.6s）：
  `[data-canvas-surface]` 1280 **672.0 → 972.0（+300.0）→ 672.0**，1440 **832.0 → 1132.0 → 832.0**；
  常驻时的宽度钉 `视口 - 608`（44 + 264 + 300），差超过 8px 就红；折起后页面级横向溢出 **0**。
- 两个入口都 ≥24×24；`aria-controls="nexus-inspector"` 指到真面板，`aria-expanded` 在「属性」上为 false。
- 臂：把 `xl:hidden` 摘掉（折起不隐藏面板）⇒ 红在「折起后属性栏应当从布局里退出」；恢复后 1 passed。
- 截图 `screenshots/studio-1280-inspector-expanded.png` / `studio-1280-inspector-folded.png`：
  折起后画布明显变宽，右缘竖排「属性」标签不压 DEMO MODE 徽标（第一版 `top-[52px]` 会压住，已改垂直居中）。
- 仍欠：属性栏折起后不记忆（见上）；<xl 的底部浮层没有"折起"概念（它本来就是浮层）。
