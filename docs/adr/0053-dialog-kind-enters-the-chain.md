# ADR-0053：对话那型也进链（**第二张配方表** + 战斗/布局两格**原样交回**）

- 状态：**已判决（并已落地）**
- 日期：2026-10-22
- 关联：§51、§52、§53、§54、§16、§159、ADR-0052、ADR-0046

## 背景

ROADMAP 那条欠条里还剩一半：

> 链上这一格只跑 RPG 那条管线——2D 那五种类型与**对话管线**在链上还没有各自的一格
> （要接得先让链上的草稿带上 kind，而不是像今天这样默认 RPG）。

ADR-0052 那一格把"草稿带上 kind"与"下游按型派"都做了 ⇒ **2D 那五型已经在链上**。
剩下的是**对话那两种**（`interactive-story` / `visual-novel`）：它们当时被**诚实拒收**（400），
理由是"链上那份配方给的是战场与战斗，而对话要的是对话实体"。

⇒ 这一格要把那条理由消掉 ⇒ **链上编得出一份对话设计**。

## 三件要定的事

### 一、配方：**换表**，不是换变体

战场那张表（玩家 / 敌人 / 物品 / 触发器 / 任务 / NPC）与对话那张表（**对话实体**）**不是同一类东西**
⇒ 变体机制（同一张表 + 每型一段）在这里用不上 ⇒ ⇒ **第二张表**：`GAME_DRAFT_SPEC_STORY`。

⇒ 对话那份：**六段对话、两个结局**（"收下这张画" / "转身离开"）。
**正文就是对话实体的说明**（`compileStory` 只读它当正文）⇒ ⇒ **正文必须干净**：
它就是播放器里显示的那段话。"配方给的起点，不是成品"那句 caveat **不进正文**
⇒ 它去**文档 summary** 与**链上那一步的 notes**（§159：措辞与真相要对上）。

⇒ **对话实体没有数值**：它的内容就是正文与选择（判定全在引用上）⇒
"每个实体都有数值"那条纪律（战场那张表的）**对对话不适用** ⇒ 这一条写进代码注释与本 ADR，
免得下一个人把"没有数值"当成"配方写坏了"。

### 二、战斗格与布局格：**原样交回**（不是失败，也不是假读数）

对话管线里**没有战斗、没有场地** ⇒ 那两格对对话型无事可做 ⇒ 三种做法：

| 做法 | 判决 |
|---|---|
| (a) 整步失败 | 否 ⇒ 一步失败会把**下游**全部牵连成 skipped ⇒ 对话那一型的试玩与投影就都跑不到了 ⇒ 等于"链上编不出对话"换个说法 |
| (b) 报一份假读数（"0 条目标达标"） | 否 ⇒ 那是把"这一格不适用"说成"这一格跑了、结果是 0"（§159） |
| (c) **原样交回**（不改任何东西、不留读数、草稿照旧往下传） | **是** |

⇒ ⇒ (c) 的三件事各有各的理由：
- **不改任何东西** ⇒ 对话那份草稿一个坐标、一个数值都不该被这两格动（它们连场地都没有）；
- **不留读数**（counts 是**空对象**）⇒ 仓库既有口径："没跑不许渲染成 0/4"⇒
  **空读数 ≠ "0 条目标达标"**，那是两件事；界面上那一格就显示"这一型没有战斗可调"；
- **草稿照旧往下传** ⇒ **链的形状不变**（九步不变、依赖不变、最后一格照旧拿到草稿去投影）。

### 三、试玩格：给**对话那套数**，不是"几种走法通关"

对话管线**没有走法**可言 ⇒ 它的报告形状本来就不同（`StoryPlaytestReport`：
可达段落数 / 可达结局数 / 空正文数 / 走不到的段落名）⇒ ⇒
把它硬凑成"通关数"就是**拿一条管线的说法去说另一条** ⇒ ⇒
这一格给**它自己的那套数**，并把"没有走法可言"写在 notes 里。

⇒ ⇒ 顺带把模型层的派发改成**三份报告的可判别联合**（`KindPlaytest`）：
按 `pipeline` 收窄 ⇒ 调用方不靠强转、也不会把某一型的字段当成别的型也有
（`maxLevel` 只有 RPG 那个成员有；`runs` 只有那两份有；`total / reachable` 只有对话那份有）。

## 后果

- **八型今天全都编得出来** ⇒ 链上不再有"编不出来"的那一型 ⇒
  ADR-0052 那句"只拦**不认识的那一型**"就是今天全部的拒收口径。
- 对话那一型在链上的读数是**它自己的那套**（可达几段 / 能停下几处 / 空正文几段）⇒
  界面上那一格说的与试玩页说的**是同一件事**（同一个 `playtestStory`）。
- 战斗/布局两格对对话型是**空读数** ⇒ 它们在进度与结论里占位，但**不报数** ⇒
  这是"这一格不适用"，不是"这一格跑了、结果是 0" ⇒ 界面上的措辞照这个口径写。
- **没做的**：界面上的类型选择器（Agent 面板那一个下拉）仍未接 ⇒ 今天只能从 API 带 `gameKind` 跑；
  §53 的 Capture screenshots / Detect bugs / Fix 三格要浏览器与模型 ⇒ 真欠。
- **一条要记住的**：三份报告形状不同 ⇒ **每一格给的是它自己那条管线的数**
  ⇒ 这条已经写进 ADR-0052 的补记（"改一半比不改更坏"）⇒ ⇒
  判据只有一条：**逐格问"这一格的读数来自哪条管线"**。
