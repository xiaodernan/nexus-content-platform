## §GATE-2 门禁死循环（ADR-0264）——一次并轨引爆的活体 bug

`verify:fe-gates` 跑了 33 分钟零输出、被杀时仍未结束。**不是慢，是 collect 阶段死循环**。

- `not-found-visual-style.test.ts` 取 CSS 段写成
  `for (let m = /\.nf-/g.exec(globals); m; m = /\.nf-/g.exec(globals))`。
  `for` 的 init 与 update **各写一遍正则字面量** → JS 每次求值产生新对象 →
  `lastIndex` 每轮回 0 → `exec` 永远返回同一个首个匹配。首个 `.nf-` 落进注释就永不返回，
  且每轮还 `matchAll` 一遍 36 万字节全文注释（O(∞) × O(n)）。
- **绿了很久的真相**：首个 `.nf-` 恰好不在注释里。`.nf-` 全文件 30 次，
  第一个在字节 3979（`BrandTitle` 那段提到 `.nf-title` 的注释，并轨带进来的），
  第一个不在注释里的是 59125。**数据巧合，不是正确性。**
- **没有一条判据变红**。所有文件"通过"，只是永远跑不完。这类故障对「测试全绿」
  完全不可见：**它不产生失败，它取消产生失败的可能**。
- **代价远大于慢**：挂在字母序 `n`，`o`–`z` 的判据从未执行。修好后第一次真跑立刻
  暴露 2 条早已红的（`publish-panel` 在 `33212785` 加了预检四行、SHA 恒等门该破没人签字；
  那四行还被写成 `.pp-note12*` 却用在 `.pb-` 组件里）。
  **一条永远跑不完的判据 ≡ 把它之后的所有判据全删掉，且不留痕迹。**
- 修法：注释区间只算一次 + `indexOf(at+1)` 正扫 + 二分判区间内。**结构上不可能自我重置**。
  二分坑：不能「`at<start` 往左、`at>=end` 往右」（落两区间之间会越界走丢），
  要找工作最后一个 `start<=at` 再判 `at<end`。
- 新增 `gate-hygiene.test.ts` 8 条（4 条是检测器自检：坏样本判违规 / 好写法不误报 /
  sticky 同族 / ≥90 套样本量兜底）。
- **注释既不喂绿也不喂红**：第一次真跑就红了——扫描器把修复注释里引用的旧代码当违规。
  「注释不得喂绿任何一道门」的镜像同样成立。
- 结果：**33 分钟零输出 → 375s / 96 套 / 1005 条（1003 通过）**。
  `tests` 只占 12.46s；collect 47.81s + prepare 40s 是大头。
- 顺手修掉并行线留下的：`.pp-note12*` 归位到 `.pb-note12*`（族按页面分）、
  那 4 行注释是 **GBK 误解码的乱码**（`)` 还原失败，直接重写）、`publish-panel` SHA 补签。
- 仍欠：fe-gates 没并行化（根 `fileParallelism:false` 是给共用 Postgres 的集成测试的，
  视觉判据跟着串行）；没超时兜底（`testTimeout` 管不到模块顶层）。

## §CACHE-3 缓存读数送到付钱的人眼前（ADR-0262 Amendment 2）

`cachedTokens` 从 ai-service 传到库里，最后一步被 `usageText()` 丢掉。补这一寸。

- 契约**加一维** `cacheReported: boolean default(false)`，不改 `cachedTokens` 为 nullable
  （老 jsonb 行会从「0」变「读不懂」，比「没记」更糟）。两个 `additionalProperties:false`
  契约都加字段 + required；ai-service 两处产出点；mock 写 `false`。
- 四档：老行/`false` → 「缓存读数未报」；`true,0` → 「缓存未命中」；`true,N` → 「命中 N·P%」。
  分母 `tokensIn`（`prompt_tokens` **含** `cached_tokens`，缓存是打折不是不计费）。
- 措辞抽到 `lib/usage-cache-text.ts`（`cacheShare`/`cacheText`/`cacheTotal`）：
  **措辞就是承诺**，钉 JSX 只能靠正则猜文本。13 条判据。
- 合计格分母**只算报过账的行**：把"没报"按 0 加进分母 = 用数据缺失伪造更差的读数。
- ai-service 305 passed / 11 skipped 无回归。
- 仍欠：Studio 内联（chat 流式 `usage` 在最后一帧）、1440/390 截图、`costUsd` 仍 0。
