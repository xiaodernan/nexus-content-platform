## §PERF-5 rankCodeFiles 去重复 toLowerCase（ADR-0157，2026-11-12）
- **接欠账**：ADR-0155 诚实边界③点名的第三处热点。`code-index.ts` `hit(haystack,token)` 每次调用对 needle/value 各 toLowerCase 一次；`rankCodeFiles` 是 O(files×tokens×fields) 嵌套循环：同 token 被小写 O(files×fields) 次、同 file 字段被小写 O(tokens) 次——**循环不变量**（toLowerCase 纯且幂等）。`context.ts:109` 每轮装配 AI 上下文重算的纯函数投影、正吃 CPU 重档。
- **先红（ spy `String.prototype.toLowerCase` 按原文 this 精确分组计数、非墙钟）**：① 文件 4→32→token 小写 184→1472（≈8×，应恒定）；② 8 files×9 字段→字段小写 472 应 72；③ token 2→7→字段 128→472；结构门红。零行为门先红时**绿**（16 组输入逐字节相等＝oracle 准、缺口纯工作量）。新建 `apps/web/test/code-index-rank-lowercase.test.ts`。
- **修法（零行为）**：tokens 预小写一次成 needles；每 file 的 path/pageName/nodeName/symbol names/externals 各预小写一次、原文留 reasons；`hit`→`hitLower(lowerValue,needle)` 热路径不再 toLowerCase；exact 判定换 `symbol.lower===needle`——**逐字节等价**：queryTokens 输出恒 `token===token.toLowerCase()`。reasons/score/find·some 短路/去重/tier/limit 全逐字节不变。
- **验证**：本片 6/6、横向 code-index 18 + complexity 7 + 本片 6 = **31/31**；eslint 两文件单进程 0、`tsc -p apps/web` 0（SIGTERM 几轮按纪律不算绿不算红、后台长窗口拿真码）。
- **变异臂 1 假绿→修实（本片最有价值教训，§CRIT-1 纪律再次生效）**：A exact 现场小写→计数门②红（80>72）；B 热路径恢复现场两点小写（幂等行为不变）→计数门①②③+结构门红；**C 原臂把反方向 `needle.includes(value)` 恒 false→假绿 rc=0**：深挖坐实该分支触发前提（`CJK_CHAR.test(needle) && needle.length>=3`）与 queryTokens 只产 CJK 单字(1)/二元组(2)、ASCII 词不含 CJK **无法同时成立**＝防御性死代码；旧 JSDoc 却声称 oracle"含反方向"＝**声称覆盖**诚实性口子。修：① 生产/判据注释改**诚实边界**明说不可达、保留为防御、不谎称覆盖；② **新增可达性门**把"含 CJK token 恒<3 字"钉死 + 正向验 CJK 二元组走正向命中（未来切词让分支复活则门红提醒补例）；③ 换 C′（exact 破坏→零行为门红 CouponCountdown）/D′（needle·value 方向反转→零行为门红）/E′（includes→startsWith→零行为门红 coupon）三条有效臂。每臂备份+md5 断言+恢复核验基线 `cfe321f2…`、只认 vitest 退出码。终态 6/6。
- **工程经验**：spy prototype 方法时取原生实现用 `Reflect.get(String.prototype,'toLowerCase')` 而非直接引用 `String.prototype.toLowerCase`（后者触发 `@typescript-eslint/unbound-method`、且语义同为替换前存下原生函数、spy 安装后不会递归拿 wrapped 自身）；oracle 复刻若直接调**导出的真实 queryTokens**可零复刻走样风险。
- **诚实边界**：纯算法优化零新功能、收益在 CPU/内存带宽；计数用 toLowerCase 调用次数作精确代理非墙钟、真墙钟待干净窗口；反方向分支当前死代码、不删、以可达性门标记、不宣称验证其运行行为；`symbols.find` 双层循环**仍线性扫符号**（本片只消重复小写、未改扫描复杂度，动它需动命中顺序语义、另立片 oracle 论证）；未 push。
