- **The hole, in amendment 535's own words.** v554's bounds said it: "The runner prints a row's output only when it reddens, so the hosted verdict is exit-based: `OK` means the harness exited 0. The `440/440` count is the local measurement of the same bytes … not a number the hosted log printed."
